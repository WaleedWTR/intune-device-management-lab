# Endpoint Management Runbook

## Daily / weekly checks

- compliance trend
- stale devices
- failed policy deployment
- failed application installation
- encryption status
- device check-in health

## Investigation flow

1. identify device and primary issue
2. confirm last successful check-in
3. inspect assigned policies
4. check deployment status
5. validate prerequisites
6. remediate or document exception
7. confirm compliance is restored
8. record recurrent failure patterns for problem management

## Data handling

Device inventories can contain personal and operational information. Export only what is required and protect/report it according to organisational policy.
